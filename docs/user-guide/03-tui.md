# TUI 与快捷键

运行 `kn` 进入终端界面。启动时顶部是欢迎卡片（版本、模型、工作目录和常用入口），下面是对话记录。输入框在底部，输入框下面的一行左侧是权限模式（以及 git 分支、目标、后台任务或临时提示），右侧是上下文占用和花费、模型和推理强度。有回合在运行时，输入框上方多一行状态：当前阶段及其用时、整轮用时、输出 token 数和 `Esc` 中断提示。有目标、计划或 subagent 时，顶部会出现一个可折叠的面板（`Alt+T`）。

在空输入框里按 `?`，或在任何时候按 `F1`，打开快捷键速查表（与 `/help` 相同，输入文字即可筛选；`/help text` 打印纯文本列表）。输入框里已有文字时，`?` 照常输入。

需要按两次的键（`Ctrl+C` 退出、`Esc Esc` 清空草稿或打开 rewind）在按第一次后，输入框下面那一行会短暂提示再按一次，过时或按了别的键后提示消失。

鼠标在输入框里：单击移动光标，拖动选择，双击选词，三击全选。

运行中输入的消息会排队，在当前工具调用结束后发送。

输入框为空时按一次 `Esc` 立即中断；输入框里有草稿（或选中了排队消息、正在编辑排队消息）时 `Esc` 先处理这些，状态行的提示随之变成 `Ctrl+C Ctrl+C to interrupt`。`Ctrl+C` 任何时候都要按两次：按第一次后状态行显示 `Ctrl+C again to interrupt`，再按一次才中断。

**Vim 模式（`/vim`）**

Vim 模式默认关闭，用 `/vim`（或 `/vim on` / `/vim off`）或 `/settings` 里的 “Vim mode” 打开，设置会保存。打开后输入框从插入模式开始，所有按键和平常一样；按 `Esc` 进入普通模式，信息栏显示 `-- NORMAL --`（插入模式显示 `-- INSERT --`）。普通模式下可打印的键是命令，不会输入文字；`Enter`、方向键、`Ctrl`/`Alt` 组合键和粘贴保持原来的作用。

| 快捷键 | 作用 |
|---|---|
| `h` / `j` / `k` / `l`（`Space` 同 `l`） | 左 / 下 / 上 / 右；在首行按 `k`、末行按 `j` 翻历史，和 `↑` / `↓` 一样 |
| `w` / `b` / `e` | 下一个词 / 上一个词 / 词尾 |
| `0` / `^` / `$` | 行首 / 第一个非空字符 / 行尾 |
| `x` | 删除光标处的字符 |
| `d`：`dd` / `dw`，`D` | 删除整行 / 删除到下一个词，`D` 删除到行尾 |
| `c`：`cc` / `cw`，`C` | 修改整行 / 当前词，`C` 修改到行尾（删除后进入插入模式） |
| `y`：`yy`，`p` | 复制整行；`p` 粘贴到光标后（整行内容粘贴到下一行） |
| `u` | 撤销 |
| `i` / `a` / `I` / `A` | 在光标前 / 光标后 / 行首 / 行尾进入插入模式 |
| `o` / `O` | 在下方 / 上方新开一行并进入插入模式 |
| `Enter` | 发送，下一条草稿回到插入模式 |
| `Esc` | 插入模式下进入普通模式；普通模式下是原来的 `Esc` |

`Esc` 的中断和回退语义保持不变，只是插入模式先吃掉一次：插入模式下 `Esc` 只切到普通模式；普通模式下输入框为空时 `Esc` 和关闭 vim 模式时一样，运行中立即中断，空闲时按两次打开回退。所以打开 vim 模式后，在空输入框里中断要按 `Esc Esc`，状态行会提示 `Esc Esc to interrupt`；`Ctrl+C Ctrl+C` 始终可用。补全菜单、排队消息和名称输入框打开时，`Esc` 先关闭它们。复制的内容只存在 vim 自己的寄存器里，不会写入系统剪贴板。

subagent 面板和 subagent 视图的按键见下文。

`/theme light|dark|auto` 切换配色，`/language zh_cn|zh_Hant|en` 切换界面语言。

编辑、写入工具的结果和审批卡片里的差异中，相邻的删除行和新增行逐行配对，配对行里改动的词用更深的底色标出；终端只有 16 色或使用单色主题时改用反色显示，纯文本输出不加任何标记。两行差别太大（共同部分不足四成）时不标出词级改动。

在 tmux 里，`Shift+Enter` 需要 tmux 打开 `extended-keys`。`kn` 不会替你修改这个服务器级选项；没打开时启动会给出提示，`/doctor` 的 Terminal 一节也会显示当前状态。在 `~/.tmux.conf` 里加上 `set -s extended-keys on` 并执行 `tmux source ~/.tmux.conf` 即可；在此之前可以用 `Ctrl+J` 或 `Alt+Enter` 换行。

在 macOS 上，`Alt` 快捷键要求终端把 Option 键当作 Meta 键发送：Terminal 在“设置 › 描述文件 › 键盘”里勾选“将 Option 键用作 Meta 键”，iTerm2 在“Settings › Profiles › Keys”里把 Left Option key 设为 `Esc+`。没有设置时 Option+O 输入的是 `ø`、Option+T 输入的是 `†`，`kn` 无法把它们和正常输入的外文字符区分开，所以默认照常输入这些字符，只在它们第一次出现在空输入框时提示一次，`/doctor` 的 Terminal 一节给出设置方法。不想改终端设置的话，可以在 `/settings` 里打开 “Option as Alt”（默认关闭）：打开后美式键盘布局下 Option+A/B/D/F/K/M/O/T/Y/Z 输入的字符会被当作对应的 `Alt` 快捷键，这些字符也就无法再输入。Option+E 在美式布局下是死键，无法映射，请用 Meta 设置。

### 把命令移到后台（Ctrl+B）

`bash` 调用运行时，工具行右侧显示 `ctrl+b 后台运行`（英文界面为 `ctrl+b to background`）。此时按 `Ctrl+B`：

- 命令不会被结束或重启：进程、沙箱和输出都保持原样，输出继续写进日志。
- 这次工具调用立即返回，结果告诉模型：用户把命令移到了后台、它的 `process_id` 和日志路径、到此为止的输出末尾，以及之后用 `ManagedProcess`（`wait`、`read_log`、`status`、`stop`）读取或停止它。这个工具在第一次移到后台后才出现在模型的工具列表里，只能查看和停止，不能启动进程。
- 命令结束时，会话会收到一条通知（带退出码和最后的输出）；空闲时这条通知会启动新的一轮。
- 移到后台之后按 `Esc` 中断本轮不会结束这个命令。`/clear`、`/resume` 切换会话和退出 `kn` 会停止它。
- 同时有几个可移到后台的调用时，`Ctrl+B` 一次移走全部（实际上 `bash` 调用彼此串行，同一时刻最多一个）。子代理里的命令不受影响。
- 没有可移到后台的命令时（包括命令已经结束、或刚按过一次），`Ctrl+B` 仍是输入框里的光标左移。交互式（`interactive: true`）命令不能移到后台。

`Ctrl+B` 是固定键位，目前没有自定义快捷键的配置。它也是 tmux 的默认前缀键：在 tmux 里要连按两次 `Ctrl+B`（tmux 把第二次按键原样发给 `kn`），或者改用别的 tmux 前缀。

## Subagent 面板与实时视图

前台和后台 subagent 都会出现在输入框下方的面板里：运行中的排在前面，已结束的随后，各组内新的在前。底部状态栏的 `⚙ N sub` 统计正在运行的 subagent 数量（含前台）。

对话记录中，每个 subagent 调用下方有一行实时状态：

```
● Subagent(Survey the loader)
  ⎿ ◌ running · 2 tools · Grep(LoadConfig) · 12s · 3.4k tok · Ctrl+T view
```

后台任务的状态行会显示任务 ID，结束后变成 `⎿ ✓ <id> done · 5 tools · 43s · 12.3k tok`。后台完成通知以状态行（`◆ subagent <id> done · …`，报告默认折叠，`Alt+O` 展开）显示，不会显示成用户输入；它以后台消息身份发给模型。

| 按键（面板聚焦时） | 作用 |
|---|---|
| `↑` / `↓` | 选择 subagent；在首行按 `↑` 回到输入框 |
| `Space` | 在面板内预览最近输出 |
| `Enter` | 打开该 subagent 的实时记录视图 |
| `Ctrl+X` | 停止选中的后台 subagent（前台 subagent 用 `Esc` 中断整个回合） |
| `Ctrl+T` | 回到输入框 |

| 按键（subagent 视图中） | 作用 |
|---|---|
| `Enter` | 运行中：补充指令（steer）；已结束：续聊（follow-up）。前台 subagent 只读 |
| `Ctrl+X` | 停止该 subagent 或当前续聊 |
| `PgUp` / `PgDn`、`↑` / `↓` | 滚动；`Ctrl+Home` / `Ctrl+End` 跳到开头 / 最新 |
| `Esc` / `Ctrl+T` | 返回主界面，焦点留在面板 |
