# 终端里的 Mermaid 图

回复中以 ```` ```mermaid ```` 开头的顶层代码块，在代码块**完整结束**（出现闭合的 ```` ``` ````）之后，会直接画成终端字符图，图上方有一行灰色说明（如 `mermaid flowchart`）。回复仍在流式输出、代码块尚未闭合时，照常显示源码，避免布局反复跳动。

图用框线字符绘制；终端使用 ASCII 字形时（设置了 `K_BRAIN_ASCII=1`，或终端、locale 不支持 UTF-8），自动改用 `+ - | . ' v ^ < >` 等纯 ASCII 字符。所有宽度都按终端显示宽度计算，中文等宽字符标签可以正确对齐。

## 支持的语法

**流程图**（`graph` / `flowchart`）

- 方向：`TD` / `TB`、`BT`、`LR`、`RL`。
- 节点：`A`、`A[矩形]`、`A(圆角)`、`A([体育场])`、`A[(数据库)]`、`A((圆))`、`A{菱形}`、`A{{六边形}}`、`A[[子程序]]`、`A>旗形]`、`A[/平行四边形/]` 等；带引号的文字和 `<br>` 换行也可以。矩形画直角框，圆角类形状画圆角框，菱形和六边形画斜角。
- 边：`-->`、`---`、`-.->`、`==>`、`--o`、`--x`、`<-->`，以及 `-->|文字|`、`-- 文字 -->`、`== 文字 ==>`、`-. 文字 .->` 等带标签写法；实线、虚线、粗线分别用不同线型绘制。
- `A --> B --> C` 链式写法、`A & B --> C` 并列写法、一行多条语句的 `;`。
- `subgraph id [标题] … end` 子图，可以嵌套，画成带标题的圆角框。
- 指向自身的边显示为节点内的 `↺` 标记。
- `style`、`classDef`、`class`、`linkStyle`、`click`、`:::类名` 等样式语句会被忽略。

**时序图**（`sequenceDiagram`）

- `participant` / `actor`，支持 `as` 别名；未声明的参与者按首次出现的顺序排列。
- 消息：`->>`、`-->>`、`->`、`-->`、`-x`、`--x`、`-)`、`--)`、`<<->>`；箭头后的 `+` / `-`（激活）会被忽略。
- 自调用（`A->>A: …`）画成回折箭头。
- `Note left of` / `right of` / `over A` / `over A,B`。
- `loop`、`alt` / `else`、`opt`、`par` / `and`、`critical` / `option`、`break`、`rect` 框，可以嵌套。
- `autonumber` 给消息编号。

## 布局方式

布局是确定性的：同一段源码在同样的宽度下总是画出同样的图。

- 流程图按层排列：先用深度优先搜索找出成环的边并把它们反向，再按最长路径分层；跨越多层的边经过中间的占位点；每层内按相邻节点位置的平均值反复排序以减少交叉，然后把节点尽量摆在与它相连的节点正中。
- 边在层与层之间的空隙里走直角折线；同一空隙里的多条折线各占一条轨道，彼此不重叠。回指的边（环）把箭头画在上游节点一侧。
- 时序图的列距按消息标签和备注的宽度自动拉开。

## 回退与截断

- 不支持的图类型（如 `pie`、`classDiagram`、`gantt`）或无法解析的源码，照常显示为代码块，并在下方加一行说明原因，例如 `mermaid: pie diagrams are not drawn in the terminal — shown as code`。
- 图比终端宽时，先把节点文字收窄换行再重新布局；仍然放不下就在右侧截断，每行末尾显示 `…`，说明行写明 `cut to N of M columns`。
- 节点超过 300 个或源码超过 64 KiB 的图不绘制，同样回退为代码块。

## 在外部查看器中打开

按 `Alt+↑` 聚焦对话记录，选中含 Mermaid 图的回复时，底部提示栏会出现 `m open diagram`。按 `m`，会把该回复里每个已闭合的 Mermaid 代码块写入系统临时目录下的 `kn-mermaid-*/diagram-N.mmd`，并用系统默认程序打开（macOS 用 `open`，Linux 用 `xdg-open`，Windows 用 `start`）。是否能看到渲染好的图，取决于系统里与 `.mmd` 关联的程序；`kn` 本身不联网、不调用任何渲染服务。
